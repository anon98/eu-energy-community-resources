# Contributing

Thank you for helping improve the **EU Energy Community Resources** collection.

## Introduction

This repository is an open resource bank for researchers, practitioners, public authorities, community organizers, energy cooperatives, technology providers, and citizens working on energy communities in Europe.

Contributions can be small or substantial. You can:

- suggest a publication, dataset, tool, standard, project, or policy resource;
- correct an outdated description or broken link;
- add a national implementation resource from an EU Member State;
- improve the organization, accessibility, or technical accuracy of the collection;
- propose a new topic when an important part of the energy-community landscape is missing.

You do not need to be a software developer. Most contributions involve editing Markdown and providing a reliable source.

### Quick contribution process

1. Create a branch from `contributions`.
2. Edit the relevant Markdown section.
3. Check the source, link, description, and access conditions.
4. Open a pull request targeting the `contributions` branch.
5. Explain briefly what you added or corrected and why it is useful.

For a simple suggestion without editing files, open a GitHub issue and include the resource title, link, and a short explanation of its relevance.

## Before opening a pull request

1. Check that the resource is not already listed.
2. Prefer an official publisher page, DOI, standards-body page, or canonical software repository.
3. Verify that the link resolves.
4. Add a concise description of the resource's research or implementation value.
5. State access or licensing limitations when they are material.

## Scope

Suitable contributions include:

- EU and national energy-community legislation and implementation guidance;
- peer-reviewed publications and authoritative technical reports;
- open-source software for community scheduling, grid analysis, flexibility, markets, and co-simulation;
- documented datasets and benchmark networks;
- interoperability specifications and standards;
- European research projects with reusable public outputs.

Avoid:

- promotional material without reusable technical content;
- duplicate links;
- unverifiable manuscripts;
- predatory publications;
- generic energy resources with no clear community-energy relevance.

## Pull-request format

In the pull-request description, state:

- what was added or corrected;
- why it belongs in the collection;
- how the bibliographic or technical details were verified;
- whether the resource is open access.

By contributing text, you agree that your contribution may be distributed under CC BY 4.0.
